# Наш сайт — 1 год и 11 месяцев ♡

Готовый статический сайт для GitHub Pages.

## Структура
- `index.html` — стартовая страница
- `question1.html` — вопрос 1
- `question2.html` — вопрос 2
- `question3.html` — вопрос 3
- `celebration.html` — поздравление + анимации + всплывающее окно
- `memories.html` — фотогалерея
- `letter.html` — отдельное письмо
- `style.css` — общий дизайн
- `script.js` — анимации и логика квеста
- `assets/` — фотографии

## Как разместить на GitHub Pages
1. Создай новый GitHub-репозиторий.
2. Загрузи все файлы и папку `assets`.
3. В Settings → Pages выбери Deploy from a branch.
4. Выбери `main` и папку `/ (root)`.
5. Сохрани — GitHub выдаст ссылку на сайт.

Все пути относительные, поэтому сайт должен корректно работать на GitHub Pages без сервера.
